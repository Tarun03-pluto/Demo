About the project

What it analyzes

How electric vehicles compare across manufacturers, prices, battery capacity, driving range and the countries where they are made.

Why EV analysis matters

Buyers, manufacturers and policymakers make decisions about cost, charging and range. Comparing vehicles side by side makes those trade-offs visible.

Why visualize the data

Charts reveal patterns, outliers and relationships that are hard to spot in a spreadsheet of rows.

How you can use it

Filter and hover inside the dashboard to compare manufacturers and vehicle attributes, then follow the story for a guided walkthrough.

Methodology

The general workflow this project follows, from raw data to a published website.

  1. Data collection

    Gather an EV dataset from a documented source.

  2. Data preparation

    Clean missing values, duplicates and inconsistent formats.

  3. Exploratory analysis

    Profile distributions and relationships between fields.

  4. Data visualization

    Choose chart types that suit each question.

  5. Dashboard development

    Combine charts and filters into an interactive Tableau dashboard.

  6. Story creation

    Sequence key views into a guided Tableau story.

  7. Web integration

    Embed the dashboard and story in this website.

  8. Testing and documentation

    Check responsiveness and embeds, then document the project.
